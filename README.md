# tailwind-neon-heaven

Sample website built with Tailwind CSS and HTML, inspired by a cyberpunk world, divided into three sections.

## Description
This project serves as a **demonstration of working with Tailwind CSS**. The main focus is on layout and styling; responsiveness and interactivity are basic.
The main goal is to **showcase the use of Tailwind utility classes**.
For a fully responsive and interactive project, visit  [career.theas.design](https://career.theas.design)
or my repositories [career-theas-design](https://github.com/TerezaJarosova/career-theas-design),
[contact-form](https://github.com/TerezaJarosova/contact-form),
[iframe-component-overlay](https://github.com/TerezaJarosova/iframe-component-overlay). 

## Technologies
- HTML 
- Tailwind CSS

## Features
- Basic responsive layout for different screen sizes
- Hover effects with gradients and rounded corners using Tailwind
- Mobile hamburger menu
- Focus on visual style and structure using Tailwind

## Running the Project
Open index.html in your browser
